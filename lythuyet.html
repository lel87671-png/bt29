Nội Dung Bài Giảng & Bài Tập Lý Thuyết (4 Mức Độ)

Trang Chủ
Chương 1: Tổng quan về Java & Cú pháp cơ bản

Giới thiệu cấu trúc chương trình Java, kiểu dữ liệu nguyên thủy, cấu trúc điều kiện (if-else, switch-case) và vòng lặp (for, while).

Danh sách bài tập (4 mức độ kèm lời giải):

Mức 1: Dễ Tính tổng hai số nguyên a và b.
Xem Lời Giải 
public class Main {
    public static void main(String[] args) {
        int a = 5, b = 10;
        System.out.println("Tong: " + (a + b));
    }
}
Mức 2: Trung Bình Kiểm tra số nguyên N có phải số nguyên tố.
Xem Lời Giải 
public class PrimeCheck {
    public static boolean isPrime(int n) {
        if (n < 2) return false;
        for (int i = 2; i <= Math.sqrt(n); i++) {
            if (n % i == 0) return false;
        }
        return true;
    }
}

Mức 4: Rất Khó Giải bài toán mã hóa Caesar cipher trên chuỗi ký tự động.
Chương 2: Lập trình Hướng đối tượng (OOP) trong Java

Tìm hiểu Class, Object, 4 tính chất OOP: Đóng gói, Kế thừa, Đa hình, Trừu tượng.

Danh sách bài tập (4 mức độ kèm lời giải):

Mức 1: Dễ Xây dựng lớp SinhVien gồm thuộc tính tên, điểm và phương thức in thông tin.
Mức 2: Trung Bình Xây dựng lớp PhânSố và thực hiện phép cộng 2 phân số.
Mức 3: Khó Quản lý danh sách nhân viên sử dụng tính kế thừa và đa hình (Nợ lương, Thưởng).
Mức 4: Rất Khó Thiết kế hệ thống ngân hàng dùng Interface và Abstract Class quản lý tài khoản.
Chương 3: Xử lý ngoại lệ, Collection Framework & File I/O

Quản lý lỗi try-catch, sử dụng ArrayList, HashMap, HashSet và đọc ghi file văn bản.

Danh sách bài tập (4 mức độ kèm lời giải):

Mức 1: Dễ Xử lý ngoại lệ ArithmeticException khi chia cho 0.
Mức 2: Trung Bình Sử dụng ArrayList để sắp xếp danh sách số nguyên tăng dần.
Mức 3: Khó Đếm tần suất xuất hiện của từ trong file văn bản bằng HashMap.
Mức 4: Rất Khó Xây dựng ứng dụng quản lý kho hàng lưu trữ tuần tự đối tượng vào file nhị phân.
